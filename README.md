# ربات اخبار فارسی تلگرام

## معرفی
ربات خبرخوان فارسی تلگرام؛ خبرها را از RSS دریافت می‌کند، بر اساس کلیدواژه‌های موجود در عنوان به «ایران» و «جهان» دسته‌بندی می‌کند و برای مشترکان می‌فرستد.

## امکانات
- دریافت خبر از بی‌بی‌سی فارسی، دویچه‌وله فارسی و یورونیوز فارسی
- ارسال خودکار خبرها با فاصله زمانی قابل تنظیم
- دسته‌بندی خبرها به ایران و جهان
- دستورات تلگرام: `/start`، `/stop`، `/news`، `/iran`، `/world`، `/sources`
- وب‌سرور Flask با مسیرهای سلامت `/`، `/health` و `/healthz`
- اجرای وب‌سرور با Waitress و اتصال به پورت متغیر محیطی Render

## ساختار فایل‌ها
- `bot.py`: منطق ربات، دریافت RSS، ارسال تلگرام و وب‌سرور Flask
- `requirements.txt`: وابستگی‌های Python
- `render.yaml`: تنظیمات استقرار روی Render
- `README.md`: مستندات پروژه و تنظیمات

## تنظیمات محیطی
این متغیرها را در بخش Environment سرویس Render وارد کنید:

| متغیر | کاربرد |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات از BotFather؛ الزامی برای فعال شدن ربات |
| `CHAT_ID` | شناسه یک یا چند چت، با جداکننده ویرگول؛ اختیاری |
| `CHECK_INTERVAL_MIN` | فاصله بررسی RSS به دقیقه؛ پیش‌فرض ۱۵ |
| `MAX_ITEMS_PER_ROUND` | حداکثر خبر در هر نوبت؛ پیش‌فرض ۱۲ |
| `DATA_DIR` | مسیر فایل وضعیت؛ پیش‌فرض `data` |
| `PORT` | پورت وب‌سرویس؛ توسط Render تعیین می‌شود |

بدون `TELEGRAM_BOT_TOKEN` وب‌سرویس و Health Check بالا می‌آیند، اما عملکرد تلگرام غیرفعال می‌ماند.

## استقرار روی Render
- نوع سرویس: Web Service
- پلن: Free
- Runtime: Python
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- Health Check Path: `/health`
- شاخه متصل به استقرار خودکار: `main`

پس از ساخت سرویس، حتماً `TELEGRAM_BOT_TOKEN` را در Environment تنظیم کنید. با هر Push به شاخه `main`، استقرار خودکار انجام می‌شود.

## نکات نگهداری
- تغییرات کد و مستندات با Commit در GitHub ذخیره می‌شوند؛ مخزن مرجع اصلی پروژه است.
- فایل وضعیت `data/state.json` شامل مشترکان و شناسه خبرهای دیده‌شده است.
- دیسک سرویس رایگان Render موقتی است؛ بنابراین فایل وضعیت ممکن است بعد از Restart یا Spin-down از بین برود. برای نگهداری دائمی وضعیت باید از دیتابیس یا فضای ذخیره‌سازی پایدار استفاده شود.
- سرویس رایگان Render در صورت بی‌ترافیکی ورودی ممکن است متوقف و هنگام درخواست بعدی دوباره راه‌اندازی شود.
